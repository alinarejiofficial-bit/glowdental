# GlowDent Digilab

Plain HTML website redesign of [glowdentdigilab.com](https://glowdentdigilab.com/).

## Open locally

Open `index.html` in your browser, or from this folder run:

```bash
start index.html
```

## Structure

```
index.html      Home
about.html      About
products.html   Products
blogs.html      Blogs
contact.html    Contact
css/styles.css  Styles
js/main.js      Interactions
favicon.svg
```
